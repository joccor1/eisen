# Content System

`Ideas` is the backlog; `Scripts` is work in progress; `Published` contains final canonical records. Use [[90-Templates/Content Brief Template]] before drafting. Every brief should link to a relevant `07-Knowledge` concept or synthesis; factual claims must retain links to `04-Research` evidence.

Publishing does not automatically rewrite knowledge. Promote only validated explanations, repeatable audience patterns, or corrected source-grounded models using [[07-Knowledge/Outputs/Output Promotion Guide]].

Supported channels: Douyin, TikTok, Newsletter, Blog, Course.
