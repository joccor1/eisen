# AI Operating Context

Before acting, read [[98-AI-Context/About Me]], [[98-AI-Context/Current Focus]], [[98-AI-Context/Knowledge Map]], [[98-AI-Context/Prompt Rules]], and [[97-AI-Memory/AI Memory Index]]. For a knowledge, research, or content task, also read [[98-AI-Context/Knowledge Iteration System]] and [[07-Knowledge/Indexes/Knowledge Index]].

Agent rules:

1. Preserve raw sources. Do not silently delete, summarize, or alter source claims.
2. Give each research note exactly one primary directory and any needed topic tags.
3. Add Topic Hub links for durable topics.
4. Treat `04-Research` as evidence and `07-Knowledge` as compiled, reusable knowledge. Do not present a research note as a cross-source conclusion without compiling and citing it.
5. File back only durable knowledge with an evidence link, date, and confidence. Write reusable models to `07-Knowledge`, operating preferences to `97-AI-Memory`, and active work to the project's `Project-Status.md`.
6. Content briefs must link to compiled knowledge; factual claims must also retain a path to the underlying research evidence.
7. The ingest ledger records history and must never block re-ingest when new context, contradictions, or stronger evidence appear.
8. Make no public publishing or remote Git push without the user's authorization.
