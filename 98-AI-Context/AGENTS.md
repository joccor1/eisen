# Agent Instructions

This vault is local-first and source-preserving. Read [[AI Operating Context]] before broad edits.

When creating a research note, set `type`, `source`, `captured`, `primary_area`, `topics`, and `tags` in frontmatter. Keep the raw import in `00-Inbox/Downloaded`; put the derived note in one `04-Research` folder; include Topic Hub links.

When a reusable, source-grounded conclusion is reached, update or create a linked concept or synthesis in `07-Knowledge` with scope, evidence, confidence, and a review date. Use `97-AI-Memory` only for durable operating preferences, decisions, and best practices. When a project advances, update its `Project-Status.md`. Do not save chat logs.

The file `07-Knowledge/.ingested.json` is a history ledger, not a completion gate. Re-ingest when new evidence changes the working model, exposes a contradiction, or makes a better synthesis possible. Follow [[Knowledge Iteration System]] for ingest, review, lint, and output feedback rules.
