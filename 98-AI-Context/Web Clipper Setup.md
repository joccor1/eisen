# Web Clipper Setup

Install the official Obsidian Web Clipper browser extension, open its options, and create a template named `Research Capture` from [[90-Templates/Research Capture]].

Set the target vault to `eisen` and the target path to `00-Inbox/Downloaded/{{title}}.md`. Map title, URL, author, published date, capture time, and page content to the fields in the template. Test once with a public article, then run [[00-Inbox/Research Collection Workflow]].

The browser extension is intentionally separate from the Vault: it requires browser-level installation and permission confirmation.
