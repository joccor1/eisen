# Knowledge Map

The system combines:

1. One primary research directory per note.
2. Multiple `topic/...` tags for cross-cutting retrieval.
3. Topic Hub links for navigation and graph context.
4. A compiled knowledge layer in `07-Knowledge` for concepts, syntheses, indexes, questions, and review state.
5. Internal links between evidence, compiled knowledge, decisions, projects, and content.
6. Selective feedback from validated content outcomes to reusable knowledge.

Start at [[04-Research/Topic-Hubs/Topic Index]] for domains or [[07-Knowledge/Indexes/Knowledge Index]] for reusable models.
