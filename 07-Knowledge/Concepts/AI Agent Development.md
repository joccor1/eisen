# AI Agent Development

## Scope

Building systems in which models use instructions, context, tools, and state to complete bounded tasks.

## Working model

An agent is more reliable when its objective, tool permissions, context source, verification step, and durable state are explicit. MCP expands the available tool surface; it does not replace clear task boundaries or review.
