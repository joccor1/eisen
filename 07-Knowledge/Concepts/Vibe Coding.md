# Vibe Coding

## Scope

AI-assisted software development where a human steers intent, constraints, evaluation, and iteration while coding tools generate and modify implementation artifacts.

## Working model

Effective Vibe Coding is not a replacement for product thinking or verification. It combines an explicit outcome, scoped context, iterative implementation, and observable checks. As work becomes more complex, the workflow benefits from specifications, reusable skills, and project state rather than only conversational prompting.
