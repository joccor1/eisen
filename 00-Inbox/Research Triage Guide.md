# Research Triage Guide

Classify each incoming item by its single strongest primary subject. Use tags for every additional subject.

| Primary signal | Destination |
| --- | --- |
| Models, agents, AI coding, MCP | `04-Research/AI` |
| Code, DevOps, GitHub | `04-Research/Software-Engineering` |
| Crypto protocols or markets | `04-Research/AI-Crypto` |
| Stocks, macro, valuation, banking | `04-Research/Finance` |
| Marketing, monetization | `04-Research/Business` |
| Visual, legal, medical domains | matching top-level research folder |

Keep uncertainty in `00-Inbox/Downloaded`; never delete the source during triage.
